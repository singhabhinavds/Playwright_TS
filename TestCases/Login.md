# Test Cases for Login Fucntionality in Salesforce

1. TC1 : Correct Login - Positive Flow

   - **Test Scenario**: User enters correct username and password.  
   - **Expected Result** : User is presented with Homepage screen.  

2. TC2 : Incorrect Password - Negative Flow

   - **Test Scenario**: User enters correct username but incorrect password.  
   - **Expected Result** : Login Error is displayed to the user.  

3. TC3 : Incorrect Username - Negative Flow

   - **Test Scenario**: User enters incorrect username but correct password.  
   - **Expected Result** : Login Error is displayed to the user.

# Test Cases for New Contacts Form Functionality in Salesforce Contacts

1. TC1 : Add New Contact with mandatory fields only

   - **Test Scenario**: When user is logged in, add new contact with mandatory fields only.
   - **Expected Result** : New contact should be added.  

2. TC2 : Add New Contact with all fields

   - **Test Scenario**: When user is logged in, add new contact with all fields. 
   - **Expected Result** : New contact should be added. 

3. TC3 : Incorrect Username - Negative Flow

   - **Test Scenario**: User enters incorrect username but correct password.  
   - **Expected Result** : Login Error is displayed to the user.
